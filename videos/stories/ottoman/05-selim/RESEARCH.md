# The Ottoman Empire 5: Selim the Grim (1512–1520) — fact check

| Claim | Fact | Source |
|---|---|---|
| Empire grew by about seventy percent in eight years (1512–1520) | ✓ ~3.4 million km² by 1520, "seventy percent during Selim's reign" | Wikipedia "Selim I"; thecollector.com "Selim the Grim" |
| Took eastern Anatolia, Syria, Egypt, the holy cities of Arabia | ✓ | Wikipedia "Selim I"; worldhistoryedu.com "Selim I" |
| 1512: pushed his father Bayezid II off the throne | ✓ (24 April 1512, with Janissary support) | Wikipedia "Selim I"; Military Wiki "Selim I" |
| Yavuz = stern / grim / resolute | ✓ | Wikipedia "Selim I"; worldhistoryedu.com |
| Safavids: new dynasty under Shah Ismail; Turkmen (Kızılbaş) followers in eastern Anatolia | ✓ | Wikipedia "Selim I" (Şahkulu, Kızılbaş); Wikipedia "Battle of Chaldiran" |
| Chaldiran, August 1514, today NW Iran | ✓ 23 August 1514, West Azerbaijan province | Wikipedia "Battle of Chaldiran"; Britannica "Selim I" (via search: 1514) |
| Ottoman cannons and muskets behind carts; Safavids had no artillery | ✓ 100–200 cannons (est.) vs none | Wikipedia "Battle of Chaldiran"; havechanged.blogspot (Chaldiran/Marj Dabiq) |
| Ismail wounded, barely escaped | ✓ | Wikipedia "Battle of Chaldiran" |

| Marj Dabiq near Aleppo, August 1516; Mamluk sultan al-Ghawri died | ✓ 24 Aug 1516 | Wikipedia "Selim I"; foreignexchanges.news "Battle of Marj Dabiq" |
