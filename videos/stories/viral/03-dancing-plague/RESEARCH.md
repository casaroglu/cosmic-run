# 03 — The dancing plague of 1518 (Strasbourg): fact check

| Claim | Fact | Source |
|---|---|---|
| 1518, Strasbourg, July | Began 14 July 1518, Strasbourg (Holy Roman Empire) ✓ | Wikipedia "Dancing plague of 1518" (https://en.wikipedia.org/wiki/Dancing_plague_of_1518); History.com "What Was the Dancing Plague of 1518?" (https://www.history.com/articles/what-was-the-dancing-plague-of-1518); Public Domain Review "The Dancing Plague of 1518" (https://publicdomainreview.org/essay/the-dancing-plague-of-1518/) |
| A woman, Frau Troffea, danced alone in the street | ✓ (named in 4 of 6 chronicles) | Wikipedia; History.com; Public Domain Review |
| For days, by later accounts | "Nearly a week" (History.com); "four to six days" (PDR) — chronicles are later accounts ✓ | History.com; Public Domain Review |
| About thirty more joined | "Some three dozen" (History.com); "more than thirty" (PDR) ✓ | History.com; Public Domain Review |
| Doctors blamed overheated blood | Physicians: natural disease from "overheated"/"hot" blood ✓ | Wikipedia; History.com; Public Domain Review |
| Officials built a stage and hired musicians | Guild halls opened, stage/platforms built, musicians hired ✓ | Wikipedia; History.com; Public Domain Review |
| It made it worse | Backfired; more people joined ✓ | Wikipedia; Public Domain Review |
| Reports say up to 400 danced | 50–400 (Wikipedia); "as many as 400" (History.com); 400 per Imlin chronicle (PDR) — disputed, script says "reports say up to" | Wikipedia; History.com; PDR |
| Some collapsed | Collapse from exhaustion ✓ | Wikipedia; History.com |
| Later accounts claim deaths | DISPUTED: contemporary Strasbourg sources don't mention deaths; "15 a day" comes from later accounts → script says "later accounts claim" | Wikipedia; Public Domain Review |
| Council banned dancing | Public dancing banned ✓ | Wikipedia; Public Domain Review |
| By September it faded | Subsided by early September ✓ | Wikipedia; History.com |
| Historians still debate why | Ergot vs. stress-induced mass hysteria (Waller) — no consensus ✓ | Wikipedia; History.com; PDR |

**Softened:** death toll ("15 people a day" not used; only "later accounts claim deaths"); number of dancers ("reports say up to 400"). Dropped: the St Vitus shrine/red shoes line (kept only as an optional visual), for time.
